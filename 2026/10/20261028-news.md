# AI 与科技晨报 2026年10月28日

覆盖区间：北京时间 **2026年10月27日08:00（含）至10月28日08:00（不含）**；对应 UTC **2026年10月27日00:00 至10月28日00:00**。以本次计划运行时刻为截止点，不纳入截止后的消息。

## 三条要点

1. **Agent 的竞争进一步转向“可执行环境 + 记忆 + 权限”。** IBM、Oracle、Akamai 同日分别从身份、企业知识、Agent Registry 和沙箱执行切入；这比单纯增加模型调用更接近企业落地。
2. **具身智能开始把“RSI”写成可观测的工程闭环，但证据仍主要来自厂商。** 智元 Genie Master 将失败反馈、检查点、策略调整和多机器人调度组成 EEP，并把 Harness RSI 与 Policy RSI 区分开来；目前没有第三方复现实验。
3. **开放模型与基础设施继续向端侧、多模态和专用场景扩展。** Liquid AI 发布 LFM3 开放权重系列；国内瑞芯微披露 AIoT 芯片增长和机器人、机器视觉等量产场景。

## 精选内容

### 1. Google DeepMind 发布 Genie 4 世界模型研究预览
- **类型：** 世界模型／生成式交互环境。
- **来源与发布日期：** [Google DeepMind 官方博客](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/introducing-genie-4/)，2026年10月27日；页面未公开具体发布时间。
- **内容：** Genie 4 被描述为实时交互式模拟模型，支持自然语言控制摄像机、天气和角色，并加入原生音频；计划向受信测试者开放，并接入 Project Genie、Gemini API 和 AI Studio。
- **为什么关注：** 真实世界 Agent 需要可交互、可持续的环境，而不只是静态图文生成；世界模型可能成为训练、评测和人机协作的基础层。
- **边界与风险：** 当前是研究预览，页面未给出完整 benchmark、训练数据或广泛可用性；“接近 AGI”的叙事不等于已验证的通用能力。

### 2. Liquid AI 发布 LFM3 开放权重多模态系列
- **类型：** 开放权重模型／端侧与多模态 Agent。
- **来源与发布日期：** [Liquid AI 官方博客](https://www.liquid.ai/blog/lfm3)，2026年10月27日；页面未公开具体发布时间。
- **内容：** LFM3 是约 1.7B–2B 规模的六模型家族，共享多模态骨干，覆盖文本、视觉、音频、全模态和决策任务；官方强调 256K 文本上下文、端侧部署以及 Agent、工具调用和机器人示例。
- **为什么关注：** 小参数、多模态和端侧推理是企业私有化、边缘设备和机器人 Agent 的重要组合。
- **边界与风险：** 评测和机器人演示主要为厂商披露；需核验具体权重、许可证、量化格式、显存占用和真实吞吐，不能把“开放权重”直接等同于完整开源。

### 3. 智元发布 Genie Master 具身 Agent 框架，提出 Physical RSI 工程闭环
- **类型：** 具身智能／Agent Harness／RSI。
- **来源与发布日期：** [IT之家报道](https://www.ithome.com/1/018/423.htm)，北京时间10月27日14:47:39（UTC 06:47:39）；[智元 AI WAVE 官方日程](https://www.agibot.com.cn/article/315/detail/250.html)确认10月27日安排。
- **内容：** Genie Master 面向智元 Genie G2 机器人在便利店中的热食打包、拣选和补货任务，使用 Embodied Execution Protocol（EEP）统一能力、指导、反馈和连续性；据报道可接收成功／失败反馈、从检查点恢复并进行多机器人调度。相关报道将“无需改模型权重的提示／记忆／执行规则优化”称为 Harness RSI，将基于数据和训练的动作策略更新称为 Policy RSI。
- **为什么关注：** 这是少数把 RSI 拆成可检查工程环节的公开案例：反馈采集、记忆、执行规则、策略训练和恢复机制。
- **边界与风险：** “行业首个”“自我进化”和效果均为厂商或媒体转述，暂无第三方 benchmark；Policy RSI 仍依赖人工接管数据和后续训练，不能表述为已实现无人监督递归自我改进。

### 4. Oracle 发布 AI Data Platform 与企业 Agent 治理能力
- **类型：** 企业 AI 平台／知识与 Agent 治理。
- **来源与发布日期：** [Oracle 官方公告](https://www.oracle.com/news/announcement/ai-world-oracle-reinvents-enterprise-computing-for-the-ai-era-with-openai-2026-10-27/)，2026年10月27日；[Oracle AI Data Platform 说明](https://www.prnewswire.com/news-releases/oracle-ai-data-platform-brings-ai-assisted-business-context-to-enterprise-ai-302920227.html)，UTC约16:00发布。
- **内容：** Oracle 描述由 AI 辅助、人工治理的业务本体和语义上下文复用，并推出 Deep Insight agents、AI Registry（登记 Agent、工具、Skills、MCP 服务器及其所有权和权限）和 Agent Hub，以连接 ChatGPT、Claude 等外部 Agent。
- **为什么关注：** 企业 AI 的难点从“接入一个模型”转向业务语义、来源、权限、生命周期和跨平台协作；Registry 与本体层正好对应这些治理问题。
- **边界与风险：** 多项能力标注为未来12个月内提供或逐步开放；Oracle 免责声明和产品路线不能视为已经完成的交付能力，实际连接范围、数据驻留和计费方式仍需核验。

### 5. Akamai 推出 Inference 与 Agent Sandbox
- **类型：** 模型推理服务／Agent 执行环境。
- **来源与发布日期：** [Akamai 官方公告](https://www.ir.akamai.com/news-releases/news-release-details/akamai-launches-ai-inference-service-and-agent-execution)，UTC 10月27日10:30。
- **内容：** Akamai 发布 OpenAI 兼容的托管推理服务，列出包括 Nemotron 3 Ultra、gpt-oss-120b、Gemma 4 在内的开放权重模型，同时提供基于 WebAssembly 隔离的 Agent 执行环境，并强调可利用边缘节点和 Blackwell Ultra 资源。
- **为什么关注：** 推理和执行分离、沙箱隔离、边缘部署和 API 兼容，是降低企业 Agent 网络延迟与权限风险的基础设施路径。
- **边界与风险：** 节点规模、模型可用区域、性能和隔离强度以 Akamai 产品信息为准；WebAssembly 沙箱不自动替代最小权限、出口控制和数据审计。

### 6. IBM 推出 Agent 身份、短期凭据和可撤销控制
- **类型：** 企业安全／Agent 身份治理。
- **来源与发布日期：** [IBM 官方新闻稿](https://newsroom.ibm.com/2026-10-27-ibm-introduces-identity-and-control-for-ai-agents,-securing-frontier-intelligence-for-the-enterprise)，2026年10月27日；页面未公开具体时间。
- **内容：** IBM 描述基于 HashiCorp Vault 的 Agent 身份、短期凭据、最小权限和撤销机制，并把 Agent 发现、评估、沙箱、终止开关、成本和 token 跟踪接入 watsonx Orchestrate；部分发现与隔离功能仍属技术预览。
- **为什么关注：** Agent 的“谁在执行、以什么权限执行、何时撤销”正在从应用代码问题上升为企业基础设施问题。
- **边界与风险：** IBM 引用的“2028 年财富500强平均拥有超过15万 Agent、仅13%具备治理”属于转述的 Gartner 数据；产品可用性分层、许可证和现有 IAM 集成仍需逐项确认。

### 7. Oracle 扩大 AI 芯片来源，加入 Google TPU、SambaNova 和 Cerebras
- **类型：** AI 算力／芯片供应链。
- **来源与发布日期：** [Reuters 报道](https://www.investing.com/news/stock-market-news/oracle-expands-chip-supply-deal-with-nvidia-adds-google-and-cerebras-offerings-4976437)，UTC约16:01发布。
- **内容：** 报道称 Oracle 与 NVIDIA 扩大 Vera Rubin 规模，并增加 Google TPU、SambaNova 和 Cerebras 推理芯片选项，同时推进自有网络系统；Oracle FY2027 资本支出目标被报道为约900亿至950亿美元。
- **为什么关注：** 大型云厂商不再只围绕单一 GPU 供应商，而是按训练、推理、网络和客户工作负载组合算力。
- **边界与风险：** 交易细节、融资结构、交付节奏和实际利用率未完全公开；资本支出目标是公司计划，不等同于已形成的有效算力。

### 8. NVIDIA、AMD 与 Meta 同日强化 Muse 模型和基础设施合作
- **类型：** 模型生态／算力与基础设施合作。
- **来源与发布日期：** [NVIDIA 官方公告](https://investor.nvidia.com/news/press-release-details/2026/NVIDIA-and-Meta-to-Expand-Collaboration-on-Muse-and-Muse-Family-of-Models-Amid-Robust-Growth/default.aspx)、[AMD 官方公告](https://ir.amd.com/news-events/press-releases/detail/1302/amd-and-meta-advance-strategic-partnership-to-power-metas-superintelligence-infrastructure)，2026年10月27日；AMD 页面对应报道时间约13:20 UTC。
- **内容：** NVIDIA 宣布扩展 Muse 模型与 Agent 优化合作，并涉及 Vera Rubin、Spectrum-X、BlueField-4 和 OpenShell；AMD 则披露 Meta 已测试 Helios 机架系统、在生产中使用 Instinct GPU，并将获得 Muse Spark Open／Muse Glimmer 的 Day-0 支持。双方公告均提到对 Meta 股权发行的投资安排。
- **为什么关注：** 模型、芯片、网络、运行时和资本绑定正在形成“全栈生态”，开放模型的可部署性会越来越受硬件与软件栈影响。
- **边界与风险：** 大规模部署、性能收益和股权交易完成均含前瞻性表述；初期系统测试不能替代长期生产数据和第三方性能评测。

### 9. 瑞芯微披露 AIoT 芯片与机器人、机器视觉等场景增长
- **类型：** 国内芯片／AIoT 产业。
- **来源与发布日期：** [上海证券报业绩披露](https://paper.cnstock.com/html/2026-10/27/content_2281572.htm)，2026年10月27日；公开报道按页面日期，具体官网发布时间未单独披露。
- **内容：** 披露显示瑞芯微前三季度营收约44.49亿元、同比增长41.64%，净利润约13.32亿元、同比增长70.90%；公司称 AIoT 产品覆盖机器人、汽车电子、机器视觉和工业应用，RK182X 进入发布／项目量产阶段，RK3572 在第三季度量产并预期第四季度放量。
- **为什么关注：** 端侧算力和专用芯片正在从概念演示转为机器人、工业视觉和汽车电子等可量产场景。

### 10. AI Native 企业平台的共同方向：语义、本体、身份、沙箱和可观测性
- **类型：** 行业观察／架构趋势。
- **来源与日期：** 由本期 Oracle、IBM、Akamai、NVIDIA 公告交叉归纳，均为2026年10月27日窗口内公开材料。
- **内容：** Oracle 强调业务本体和 Agent Registry，IBM 强调短期身份与撤销，Akamai 强调隔离执行，NVIDIA 强调 OpenShell/Sentry 运行时；这些能力共同构成 AI Native 企业的“控制面”。
- **为什么关注：** 企业从 PoC 进入生产后，决定成败的往往不是再换一个模型，而是能否把知识、权限、执行、成本、审计和恢复机制连成闭环。
- **边界与风险：** 这是基于多家厂商公开材料的分析，不是独立市场份额结论；各产品之间尚未形成统一标准，互操作性和迁移成本仍未知。

## 热点事件

### 具身智能把 RSI 从口号推进到流程设计
- **事实：** 智元公开 Genie Master、EEP、反馈恢复和多机器人调度，并将 Harness RSI 与 Policy RSI 分开描述。
- **为什么受关注：** 具身系统可以把失败、恢复、策略变化和任务结果记录为工程数据，比纯文本 Agent 更容易定义“改进是否发生”。
- **仍未知：** 真实任务成功率、长期稳定性、人工介入比例和策略更新的自动化程度尚未由第三方公开验证。
- **分析：** 目前更准确的说法是“面向 Physical RSI 的工程框架和业务验证”，而不是已经证明的递归自我改进系统。

### 算力供应链从单一 GPU 采购转向异构协同
- NVIDIA、AMD、Google TPU、SambaNova、Cerebras 和 Oracle 自有网络同时出现在本窗口的企业公告和报道中。
- 可能影响包括：训练与推理分工更细、模型需要适配多种编译和运行时、企业更重视可迁移性与供应链议价。
- 交易规模、交付和性能收益仍以公司公告和媒体报道为准，不能把资本承诺直接视为已上线容量。

### 国内 AIoT 与物理 AI 产业继续向量产和场景验证靠拢
- 瑞芯微披露机器人、机器视觉和工业应用的芯片量产进展；智元把机器人 Agent 放入便利店任务。
- 两者分别代表端侧算力底座和具身应用上层，但尚不能据此判断整个行业已完成规模化商业闭环。
