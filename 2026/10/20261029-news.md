# AI 与科技晨报 2026年10月29日

覆盖区间：北京时间 **2026年10月28日08:00（含）至10月29日08:00（不含）**；对应 UTC **2026年10月28日00:00 至10月29日00:00**。以本次计划运行时刻为截止点，不纳入截止后的消息。

## 三条要点

1. **企业 Agent 的核心竞争转向 Harness 与治理。** Microsoft/GitHub 发布 Copilot Harness，多模型编排、MCP、Skills、插件和长任务管理进入企业产品；OpenAI 与 ServiceNow、ServiceNow Control Tower 也把权限、上下文和工作流动作纳入统一控制面。
2. **AI for Science 从“模型演示”转向机构化部署。** Anthropic 扩大科学机构支持，Meta 与五所美国高校共建医学和科学项目；公开材料仍主要是机构和公司披露，成果质量需后续独立评估。
3. **国内出现面向 Agent 基础设施和 AI 芯片的产业信号。** 无问芯穹披露 SOL‑ExecBench GPU Kernel 竞赛成绩及 Agentic Infra/RSI 闭环；杭州微纳核芯宣布超过10亿元 C2 融资并推进近存算芯片，均应区分公司口径与已验证性能。

## 精选内容

### 1. Microsoft/GitHub 发布 Copilot Harness，推进多模型 Agent 工作
- **类型：** Coding Agent／Harness／企业平台。
- **来源与发布日期：** [Microsoft 官方博客](https://blogs.microsoft.com/blog/2026/10/28/introducing-the-microsoft-copilot-harness-unlocking-the-potential-of-truly-multi-model-agentic-work/)，UTC 2026年10月28日16:51:35。
- **内容：** Copilot Harness 在 Microsoft Foundry 中提供多模型 Agent 编排，支持 MCP、Agent Skills、插件、托管 Agent、20多个前沿模型和长时间运行任务，并与 GitHub Copilot 体系连接。
- **为什么关注：** Coding Agent 的产品边界从单模型问答扩展到模型路由、工具调用、上下文、权限和长任务管理。
- **边界与风险：** 这是微软产品公告，实际模型覆盖、区域可用性、价格和企业数据边界需以产品文档为准；Harness 不会自动解决错误执行和提示注入。

### 2. Anthropic 扩大 AI for Science 机构支持
- **类型：** AI for Science／机构合作。
- **来源与发布日期：** [Anthropic 官方公告](https://www.anthropic.com/news/ai-for-science-expands-foundations-research-institutions)，2026年10月28日；页面未公开具体时间。
- **内容：** Anthropic 宣布向包括 NSF、Sloan、Simons、STScI、EMBL 等科学基金会和研究机构提供 Claude 额度与支持；公告提到 Allen Institute 等团队使用多 Agent 分析开放数据集，并产出数据、软件和标准。
- **为什么关注：** AI 科研应用正在从个人试用转向机构级资源、数据和工作流协作。
- **边界与风险：** 公告披露的是支持计划与案例方向，不等于科研成果已通过同行评审；数据许可、可重复性和模型错误仍需机构自行治理。

### 3. Alphabet Q3 业绩披露 Gemini 与 Agent 业务规模
- **类型：** 公司业绩／模型平台。
- **来源与发布日期：** [Google CEO 官方信](https://blog.google/company-news/inside-google/message-ceo/alphabet-earnings-q3-2026/)，2026年10月28日；页面未公开具体时间。
- **内容：** Alphabet 披露收入同比增长25%、Cloud 增长103%，Gemini API 处理量约每分钟320亿 token；同时介绍 Gemini 4 Carbon、Genie 4 世界模型和更长程 Agent 计划。
- **为什么关注：** 这类披露把模型使用量、云业务和 Agent 产品路线放在同一经营指标体系中。
- **边界与风险：** 用户量、token 量和模型排名均为公司披露；季度增长不等于单个模型的独立质量或长期利润。

### 4. OpenAI 与 ServiceNow 扩大企业工作流合作
- **类型：** 企业 Agent／工作流治理。
- **来源与发布日期：** [OpenAI 官方公告](https://openai.com/index/openai-servicenow-partnership-expansion/)，2026年10月28日；页面未公开具体时间。
- **内容：** ServiceNow 上下文与可治理动作接入 ChatGPT，Action Fabric 负责组织权限；双方计划将 Codex 接入 AI Workflow Factory，并推进网络安全与语音风险评估方案。
- **为什么关注：** 企业 Agent 需要在真实系统里读取上下文、执行动作并遵守组织权限，这比独立聊天窗口更接近生产价值。
- **边界与风险：** 部分能力为分阶段或计划提供；企业需验证动作审批、审计、数据驻留和失败回滚，不应把集成公告视为已经完成的全自动流程。

### 5. ServiceNow 发起 Control Tower Alliance
- **类型：** Agent 治理／行业生态。
- **来源与发布日期：** [ServiceNow 官方新闻稿](https://newsroom.servicenow.com/press-releases/details/2026/ServiceNow-launches-Control-Tower-Alliance-to-help-enterprises-adopt-AI-safely-at-scale/default.aspx)，2026年10月28日；页面未公开具体时间。
- **内容：** 联盟成员包括 Anthropic、AWS、Cisco、HiddenLayer、Kong、NVIDIA、Okta、OpenAI、Stripe、WitnessAI 和 Zenity，目标是提供经过整理的集成、风险控制与企业 Agent 控制平面。
- **为什么关注：** 供应商开始围绕身份、监控、策略和第三方工具建立 Agent 治理生态，而不只是销售模型 API。
- **边界与风险：** 联盟成员不代表统一标准或互操作性已经形成；客户仍需核验各成员产品的日志、权限、锁定和退出成本。

### 6. Rime 发布可微调企业语音到语音模型 Prism
- **类型：** 语音模型／企业 Agent。
- **来源与发布日期：** [Rime 官方介绍](https://www.rime.ai/resources/prism-first-speech-to-speech-for-enterprise)，[PR Newswire](https://www.prnewswire.com/news-releases/rime-launches-prism-the-first-fine-tunable-frontier-speech-to-speech-model-302922665.html)，2026年10月28日20:05 UTC。
- **内容：** Prism 主打可微调的语音到语音交互，官方称首次音频约500–570毫秒，支持在语音输出前保留文本检查点、并行工具调用、私有云／本地部署和测试阶段的微调。
- **为什么关注：** 文本检查点、工具调用和私有化让实时语音 Agent 更容易接入审计、审批和企业知识系统。
- **边界与风险：** 延迟与 τ-Voice 分数为公司 benchmark；真实噪声环境、语言覆盖、隐私处理和长对话稳定性仍需独立测试。

### 7. Arm 与 Oracle 计划面向 Agent 工作负载的 AGI CPU
- **类型：** 芯片／云基础设施。
- **来源与发布日期：** [Arm 官方公告](https://newsroom.arm.com/news/arm-agi-cpu-oracle-cloud-infrastructure)，2026年10月28日；页面未公开具体时间。
- **内容：** Arm 与 Oracle 计划在2027年秋季将 Arm AGI CPU 引入 OCI，面向代码执行、数据检索、工具调用和 Agent 协调等 CPU 密集工作负载。
- **为什么关注：** Agent 工作负载不只有 GPU 推理，还包括大量调度、检索、沙箱和工具链计算，云厂商开始为此单独设计 CPU 路线。
- **边界与风险：** 目前没有公开规格、benchmark 或价格；“面向 Agent”是产品定位，不等于已证明的成本或性能优势。

### 8. Meta 与五所美国高校共建医学和科学 AI 项目
- **类型：** AI for Science／大学合作。
- **来源与发布日期：** [Meta 官方新闻稿](https://about.fb.com/news/2026/10/meta-partners-with-five-us-universities-to-accelerate-medical-and-scientific-breakthroughs/)，2026年10月28日；页面未公开具体时间。
- **内容：** Meta 与 Caltech、Ohio State、LSU、Indiana、UTHealth Houston 合作，提供约200万美元资助、模型和协作支持，项目涉及婴儿气管切开监测、失智症对话 AI、心衰风险预测、化学与数学基准。
- **为什么关注：** 大模型公司开始以开放数据、专用模型、研究资助和学术验证组合推进科学应用。
- **边界与风险：** 资助和合作项目尚不等于临床或科研结论；医疗场景需要隐私、偏差、临床验证和责任归属审查。

### 9. 无问芯穹披露 GPU Kernel Agent 与 RSI 工程闭环
- **类型：** 国内 Agent Infra／GPU 优化／RSI。
- **来源与发布日期：** [无问芯穹官方文章](https://www.infinigence-ai.com/news-updates/250.html)，2026年10月28日；页面未公开具体时间。
- **内容：** 公司披露在 NVIDIA Research SOL‑ExecBench 四个赛道取得全球第一或前列，并介绍“代码生成→容器执行→性能分析→记忆／Skills 反馈”的 Agentic Infra 环路，将优化后的 kernel 回灌到训练和推理流程，再改进规划、工具和记忆。
- **为什么关注：** 这是把 RSI 具体化为可测量的工程闭环：生成、执行、评测、记忆和回灌，而不是只用“自我进化”作营销表述。
- **边界与风险：** 排名和改进效果为公司及基准披露，底层排名日期早于文章发布；需独立复现任务覆盖、硬件环境、人工介入比例和收益是否可迁移。

### 10. 扩散智能开源 Clover-35B-A3B-Preview，探索高吞吐 Agent 编程模型
- **类型：** 开放模型／Coding Agent。
- **来源与发布日期：** [模型发布报道](https://finance.sina.com.cn/roll/2026-10-28/doc-iniwuqvx5958495.shtml)，2026年10月28日19:20；[Hugging Face 模型仓库](https://huggingface.co/Diffuspace/Clover-35B-A3B-Preview)、[GitHub 仓库](https://github.com/DiffuSpace/Clover-35B-A3B-Preview)。
- **内容：** Clover-35B-A3B-Preview 采用35B总参数、约3B激活的 MoE 扩散式语言模型，公开模型权重和代码，面向代码、工具调用和决策任务；公司称其在同规模六项 Agent 编程／工具 benchmark 中领先，并在单张 GB300 上达到约680 token/s。
- **为什么关注：** 这是窗口内可核验的国内开放模型发布，重点在扩散式生成、低激活参数和 Coding Agent 高吞吐。
- **边界与风险：** 评测和吞吐为公司测试或媒体转述，尚无独立复现；Preview 版本、硬件依赖、推理框架和许可证条款需在仓库中逐项核验，不能把单卡结果外推到通用部署。

## 热点事件

### 企业 Agent 进入“控制面”竞争
- **事实：** Microsoft Copilot Harness、OpenAI-ServiceNow、ServiceNow Control Tower、Anthropic 科学计划和 Meta 学术合作均把模型置于组织权限、工作流、数据和评估体系中。
- **为什么受关注：** 企业采购从“哪个模型更强”转向“谁能控制 Agent 的身份、上下文、工具、审计、成本和退出”。
- **分析：** 这是一种基于多家公告的架构趋势判断，不代表已经形成统一标准；实际落地仍取决于权限模型和数据治理。

### AI for Science 进入机构化扩张
- Anthropic 和 Meta 同日发布面向科学机构与高校的支持计划，覆盖开放数据、医学监测、化学、数学和科学软件。
- 可能影响包括：科研数据和模型的共同建设加快，机构对可重复性、数据许可和模型审计的要求提高。
- 当前公开材料仍以计划、资助和案例为主，不应提前宣称临床或基础研究突破。

### 国内 RSI 叙事更强调工程证据
- 无问芯穹把 RSI 写成 kernel 生成、容器执行、性能分析和记忆回灌；这与此前具身智能中的失败反馈、检查点和策略更新属于同一类“可观测闭环”。
- 需要区分人工主导的自动化优化、依赖人工数据的策略训练，以及真正能够自主提出、验证并部署下一轮改进的递归自我改进。本期没有独立证据证明后一种能力已在生产中成立。
