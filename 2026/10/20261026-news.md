# AI 与科技晨报 2026年10月26日

覆盖区间：北京时间 **2026年10月25日08:00（含）至10月26日08:00（不含）**；对应 UTC 2026-10-25 00:00 至 2026-10-26 00:00。以计划运行时刻为截止点，不纳入截止后消息。

## 三条要点

1. **自托管 AI 应用的凭据安全值得优先检查。** big-AGI 2.1.2 修复服务端 Gemini 密钥可能经调试请求回显暴露的问题，项目方建议受影响部署升级后轮换密钥；目前没有据此确认在野利用或大规模泄露。详见精选1。
2. **Agent 工程更新集中于上下文与授权边界。** Open WebUI 增加 Skills 按需加载和压缩过程展示，并收紧工具连接及共享权限；Windmill、OpenHarness 分别更新逐用户身份联邦和团队机器身份。详见精选2、5、6。
3. **国内模型有可核实的工程变更，但不能当成新模型首发。** Ling 修复 MTP 训练损失路径；Nanbeige4.3-33B 补齐模型卡，并把配置上下文明确为512K。前者不是权重升级，后者权重已在前一天上传。详见精选3、4。

## 精选内容

### 1. big-AGI 2.1.2 修复服务端 Gemini 密钥暴露路径
- **类型：** 开源应用／安全更新。
- **来源与发布日期：** 项目官方 GitHub Release；UTC 10月25日04:42:10，北京时间12:42:10。
- **内容：** 发布说明指出，设置服务端 `GEMINI_API_KEY` 的部署可能通过 AI Inspector 的请求回显暴露密钥，本版关闭该路径，并建议相关自托管用户升级后轮换密钥。另新增会话内容块编辑与重排、流式 Render Tree，以及受预算约束的重试处理。
- **为什么关注：** 调试与可观测界面也属于安全边界，不能默认其中展示的请求数据适合发送给客户端。
- **边界：** 以上漏洞与修复情况据项目方说明；未独立审计或确认实际受害情况。更新模型目录不代表目录中的模型当天首次发布。
- **原始链接：** [发布说明](https://github.com/enricoros/big-AGI/releases/tag/v2.1.2)。

### 2. Open WebUI 0.12.4 加入 Skills 按需加载和可见的上下文压缩
- **类型：** 源码可用应用／Harness。
- **来源与发布日期：** 官方 GitHub Release；UTC 10月25日08:07:13，北京时间16:07:13。
- **内容：** 新增按需加载选中 Skills 的选项，默认关闭且依赖内置 Skills 工具；聊天可显示压缩发生位置和摘要，临时聊天及工具输出很长的短会话也可触发压缩。关闭 Direct Integrations 现在会停用已保存的相关连接，共享权限同时在 API 层执行。
- **为什么关注：** 这些变化有助于管理上下文占用、追溯压缩后信息，并让权限设置真正约束工具访问。
- **风险：** Docker 基础环境改为 Python 3.12／Debian 13，自定义工具需做兼容测试；旧连接可能因默认关闭的 Direct Integrations 而失效。隐藏控件本身不等于撤销底层权限。
- **原始链接：** [发布说明](https://github.com/open-webui/open-webui/releases/tag/v0.12.4)。

### 3. 蚂蚁百灵 Ling-3.1-flash 合并 MTP 训练损失修复
- **类型：** 模型仓库重要提交。
- **来源与发布日期：** inclusionAI 官方 Hugging Face 仓库；合并提交 UTC 10月25日14:23:35，北京时间22:23:35。
- **内容：** 修复多 token 预测（MTP）已禁用却仍计算相关损失，以及监督目标为空时产生 NaN、污染主损失的问题，并处理多层 MTP 遍历。
- **为什么关注：** 对使用仓库自定义代码进行训练或微调的团队，这是训练稳定性问题，而非榜单或推理效果更新。
- **证据与局限：** PR 提供小型随机权重的 CPU 回归测试，不能替代完整权重及所有内核路径测试；显式 shift_labels 的目标对齐仍有待后续处理。本次未修改模型权重，不宜宣称所有 MTP 问题已解决。
- **原始链接：** [合并讨论与测试说明](https://huggingface.co/inclusionAI/Ling-3.1-flash/discussions/7)、[提交记录](https://huggingface.co/inclusionAI/Ling-3.1-flash/commits/main)。

### 4. Nanbeige4.3-33B 补齐模型卡与部署资料，配置上下文改为512K
- **类型：** 开放模型文档／配置更新，非首次发布。

- **边界：** 权重上传发生于 UTC 10月24日，不算本窗口新模型。模型卡分数为项目方报告，未独立复现；教师模型定位也不表示相应学生模型已发布。

### 7. llama.cpp b11888 修复语法约束下长 token 被误拒问题
