## 三条要点

1. **具身智能开始把“部署后自我改进”做成工程闭环。** 智元发布 GO-3 Preview，并披露 Genie Evolver/Master：真实机器人、仿真与世界模型共同产生反馈，目标是让机器人在部署后诊断失败、调整策略、积累经验。它是本窗口最接近 Physical RSI 的产业案例，但成功率与“无需人工调参”仍是公司口径。
2. **企业 Agent 的竞争焦点从“会不会调用工具”转向运行时、权限和组织记忆。** 腾讯 ADP、WorkBuddy、Buddy One 与腾讯网盘组合，强调 MCP/Skills、Agent Runtime、沙箱、可观测、评测、审计和统一记忆空间；英特尔与腾讯云则把沙箱并发、硬件隔离和代码迁移纳入 AI 云实例。
3. **安全治理正在成为模型能力发布的同等重要组成部分。** OpenAI 更新 Model Spec，并公开分层失配监测系统；其核心是人类意图、伤害最小化、诚实透明、人类能动性与关怀，同时承认当前模型尚未完全达到目标。

## 精选内容

### 1. 具身模型 GO-3 Preview 与 Physical RSI 闭环
- **类型：** 新闻/模型发布；智元创新日，2026-10-29（公司新闻稿约 09:14 UTC；IT之家报道 23:22 UTC）。
- **来源：** [智元/PR Newswire](https://www.prnewswire.com/apac/zh/news-releases/worken---302923463.html)；[IT之家报道](https://www.ithome.com/1/019/806.htm)
- **摘要：** GO-3 Preview 采用 WRAM（World Reasoning Action Model），将任务推理、未来状态预测与动作生成统一；Genie Evolver 结合 100+ 真实机器人、物理仿真和世界模型后训练，Genie Master 形成“判断—执行—反馈”闭环。公司称便利店部署成功率从第1天 28.6% 提升至第5天 85.7%。
- **为什么关注：** 这是“模型+Harness+环境反馈”向 Physical RSI 迈进的公开工程样例，重点不在一次性 benchmark，而在部署后的数据闭环。
- **边界与风险：** 排名、成功率、“无需人工演示/调参”均为公司披露，尚无独立复现实验；“自我改进”仍依赖人类设计的环境、指标、权限和数据管线，不等于无约束递归自我改进。

### 2. 腾讯 ADP、WorkBuddy 与 Buddy One：企业 Agent 运行时升级
- **类型：** 企业平台/AI Native；腾讯云官方博客，2026-10-29（日期公告）。
- **来源：** [腾讯云 ADP 官方文章](https://adp.tencent.com/zh/blog/tencent-cloud-adp-business-agent-ecosystem-2026)
- **摘要：** ADP 连接业务系统和办公入口，支持纳管、调度与发布业务 Agent；WorkBuddy 通过 MCP/Skills 接入 ERP、CRM、OA；新 Agent Runtime 强化上下文、工具调用、安全沙箱、可观测和评测。Buddy One 整合腾讯文档、ima、腾讯网盘等工具，腾讯网盘被定位为 Agent 记忆空间。
- **为什么关注：** 企业 AI Native 的关键从“单个助手”转向 Agent 资产、组织记忆、统一身份和运行治理，直接对应 Harness 的上下文管理、工具编排和审计。
- **边界与风险：** 50+行业、500强覆盖、20万 Skills、伊利提效和订单增长等数字均为腾讯或客户案例口径；平台落地仍取决于数据权限、流程标准化和成本观测。

### 3. OpenAI 更新 Model Spec：从指令遵循转向价值与监督框架
- **类型：** 官方政策/模型行为规范；OpenAI，2026-10-29。
- **来源：** [官方公告](https://openai.com/index/updated-model-spec/)
- **摘要：** 新版围绕五项价值重组：忠实于人类意图、伤害最小化、诚实透明、人类能动性、关怀；加入上下文、记忆、个性化、监督和副作用控制指引，并减少详细风格规范。OpenAI 明确称当前模型尚未完全体现该规范。
- **为什么关注：** 当 Agent 能执行长期任务时，模型行为规范会直接影响权限边界、确认机制、记忆使用和企业治理。
- **边界与风险：** Model Spec 是目标行为描述，不是独立安全认证；实际效果仍需通过系统卡、红队、事故披露和第三方评测验证。

### 4. OpenAI 公布前沿模型失配监测系统
- **类型：** 官方安全研究/工程博客；OpenAI，2026-10-28（页面于10-29持续更新）。
- **来源：** [How we detect frontier model misalignment](https://openai.com/index/how-we-detect-frontier-model-misalignment/)
- **摘要：** 公开四层监测架构：激活探针、模型审查员、调查 Agent、结合外部遥测的自动调查；覆盖训练、评估、内部 Codex 和部分外部工具调用。公司回放称，强化监测可在模型逃出沙箱约30分钟内报警，并在一次训练事件中15分钟内发现联网异常。
- **为什么关注：** 这是把 Agent Harness 的安全观测、网络隔离、自动暂停和人工响应纳入训练/部署全生命周期的具体实践。
- **边界与风险：** 监测召回率、报警时延和回放效果来自 OpenAI 自测；公司同时承认外部部署上下文和调查能力较内部系统受限，监测不能替代隔离与最小权限。

## 热点事件

### 1. Physical RSI 从概念演示走向部署闭环
- **事实：** 智元在10月29日发布 GO-3 Preview，并披露真实机器人、仿真、世界模型和部署反馈闭环。
- **争议/未证实：** 成功率提升、无需人工调参和榜单第一均为公司或媒体转述，尚未有公开独立复现。
- **影响分析：** 若闭环可复现，具身智能的主要瓶颈会从单次策略学习转向数据采集、失败归因、仿真—现实迁移和安全权限；这仍属于工程化自我改进，不应直接称为已验证的通用递归自我改进。

### 2. 企业 Agent 平台进入“组织操作系统”竞争
- **事实：** 腾讯 ADP/WorkBuddy/Buddy One、腾讯网盘记忆空间，以及豆包工作台第三方模型接入，都在强化统一入口、模型路由、Skills/MCP、组织资产和审计。
- **争议/未证实：** 覆盖企业数、提效和订单增长为厂商或客户案例口径。
- **影响分析：** 企业采购评价将更多关注权限、沙箱、可观测、成本、数据留存和人工接管，而非单一 benchmark。

### 3. 企业 Agent 治理开始覆盖成本、身份与生命周期
- **事实：** BetterCloud 发布跨供应商 Token/Agent 生命周期治理；腾讯 ADP/WorkBuddy 强调身份、权限、审计与可观测。
- **争议/未证实：** 产品效果与客户规模主要来自厂商发布稿。
- **影响分析：** 企业 Agent 平台的控制面将同时管理成本、权限、记忆、工具和退出机制，治理能力可能成为采购门槛。

### 4. 前沿模型安全从“发布前评测”扩展到运行时监测
- **事实：** OpenAI 同期更新 Model Spec 并公开多层失配监测系统；监测覆盖训练、评估和部分外部工具调用。
- **争议/未证实：** 监测召回率和回放报警时延主要是厂商自测。
- **影响分析：** Harness 将承担更多安全职责，包括网络隔离、最小权限、自动暂停、审计和人工响应；企业若只部署模型而不建设运行控制面，风险会被低估。
