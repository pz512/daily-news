1. **Agent 工程更新继续收紧执行与恢复边界。** ADK Python 2.14.0 改用验证后的脚本路径和参数执行技能，LiteLLM LTS 修复大结果返回及重复审核问题。已有部署应先看兼容性和回归测试，再决定升级。

## 精选内容

### 1. Agent Harness｜Codex 合入增量工具目录设计

- **来源/时间**：PR #60163 于 2026-11-07 19:26:34 UTC 合并（北京时间 11 月 8 日 03:26:34）。[公开 PR](https://github.com/openai/codex/pull/60163) · [对应实现](https://github.com/openai/codex/blob/33b3f80a0935e51a49cbbda7d6473ef757d4241b/codex-rs/core/src/tools/spec_plan.rs)
- **摘要**：会话里的工具目录发生变化时，增量追加工具定义、命名空间说明或移除记录，减少反复发送完整执行工具声明；公共执行说明与共享类型保留到上下文压缩时再刷新。
- **为什么关注**：工具数量动态变化的 Agent 需要管理声明、权限与上下文的一致性，这个实现提供了一个可读的设计样本。
- **边界**：这是源码合并观察，不是新正式版本公告。代码要求 Responses Lite、增量工具相关开关及 Code Mode 的特定组合；没有本次改动的公开性能数字，不能宣称已普遍开放或量化节省了多少 token。

### 2. 日期级参考｜Grok API 水印规则进入标注生效日

- **来源/日期**：官方文档写明自 2026-11-07 起生效，未披露时区与时刻；页面注明上次更新为 10 月 31 日，因此这是此前公布规则的生效参考，并非 11 月 7 日新公告。[官方水印文档](https://docs.x.ai/developers/advanced-api-usage/watermarking)
- **摘要**：列出的 Grok 4.7、4.6、4.5、4.3 与 4.20 系列模型默认在 API 文本输出中加入水印，覆盖普通文本、结构化输出和工具调用参数。接入方可检查响应头 `x-watermark`，确认本次响应是否加印。
- **为什么关注**：Agent 的工具参数也属于生成输出，来源标识需要与参数校验、内容正确性分别处理。
- **边界**：官方称水印通过调整 token 采样分布实现，不插入隐藏字符；检测是统计性的，可能返回“不确定”。管理员按模型退出有适用条件，部分模型会被锁定。本文未独立验证检测准确率，也不作法律合规判断。

- **来源/日期**：官方活动文档写明北京时间 2026-11-07 起，未给出具体时分，无法仅凭日期确认严格落入本期 24 小时窗口。[官方活动说明](https://docs.qoder.cn/events/qoduck-free)

- **为什么关注**：适合用实际任务比较匿名模型的效果，同时核对额度用尽后的计费方式。
- **边界**：模型身份、具体免费次数与活动结束日尚未公布。活动适用产品为 Qoder CN，文档明确 Qoder CN IDE、JetBrains 插件和 CLI 暂不支持；团队及企业订阅不适用。不能据此推断 Qoduck 的底层型号。

### Qwen Code v0.27.0｜本地子任务问答与审批流程改进

- **发布时间**：2026-11-07 20:45:25 UTC（北京时间 11 月 8 日 04:45:25）；**状态/许可**：正式版，Apache-2.0。
- [版本公告](https://github.com/QwenLM/qwen-code/releases/tag/v0.27.0) · [版本许可证](https://github.com/QwenLM/qwen-code/blob/v0.27.0/LICENSE)
- **更新与场景**：纳入本地 FileChanged hooks、普通本地会话一级子任务的独立待答问题，并修复交互式 TUI 中后台 workflow 审批无法响应而卡住的问题。对同时推进多个编码任务的使用者，价值在于文件变化集成、子任务问答和可操作的审批。
- **范围与风险**：FileChanged 仅支持本地非托管会话，文件系统通知不保证完整，初始扫描、对账和防止自触发循环仍由集成负责。并发问答也只覆盖规定的本地工具和一级子任务，不涵盖 SSH、MCP、Hooks、Team、workflow 或更深子任务，不能概括为全模式并行人审。[Hooks 范围](https://github.com/QwenLM/qwen-code/pull/13969) · [问答范围](https://github.com/QwenLM/qwen-code/pull/16484) · [审批修复](https://github.com/QwenLM/qwen-code/pull/16432)
- **去重**：同日凌晨发布的 nightly 不单列，采用随后发布的正式版。

### Google ADK Python v2.14.0｜执行环境转稳定，同时包含不兼容变更

- **发布时间**：2026-11-07 00:58:18 UTC（北京时间 08:58:18）；**状态/许可**：正式版，Apache-2.0。
- [版本公告](https://github.com/google/adk-python/releases/tag/v2.14.0) · [发布时间元数据](https://api.github.com/repos/google/adk-python/releases/tags/v2.14.0) · [版本许可证](https://github.com/google/adk-python/blob/v2.14.0/LICENSE)
- **更新与场景**：执行环境、A2A 和多项评估功能从实验状态转为稳定；新增重复及并行评估、工具参数语义匹配。环境模式下的 RunSkillScriptTool 改用验证后的脚本路径与参数，发布说明称这修补了提示注入模型可执行任意 shell 命令的入口。
- **升级风险**：旧的自由 `command` 调用会被拒绝；Enum 工具参数改为枚举成员，依赖原始字符串的代码需要调整。新版写入的 Firestore 会话无法由 2.13.0 及更早版本读取，回滚前必须考虑数据兼容性。建议在副本中验证技能调用、审批、会话读写与恢复。
- **时间与效果边界**：更新日志标题写 11 月 4 日，本期采用平台实际 Release 时间 11 月 7 日，不宣称全部功能当天首次出现。维护者的特定多轮工作流提速数据未独立复现，不推广为所有任务的收益。

### LiteLLM v1.108.3 LTS｜修复大 MCP 结果和重复审核

- **发布时间**：2026-11-07 22:29:58 UTC（北京时间 11 月 8 日 06:29:58）；**状态/许可**：非预发布 LTS；`enterprise/` 之外为 MIT，企业目录另有许可。
- [版本公告](https://github.com/BerriAI/litellm/releases/tag/v1.108.3) · [版本许可说明](https://github.com/BerriAI/litellm/blob/v1.108.3/LICENSE)
- **更新与场景**：修复 MCP 工具结果超过 1 MiB 时 SSE 无响应失败，发布说明称该回归始于 1.103.0；修复模型级 post-call guardrails 对同一响应重复检查，以及 Bedrock 的 `api_base` 为空字符串时请求失败。
- **为什么关注**：已部署模型代理、MCP 或审核链路的团队，可优先检查是否受这些具体问题影响。
- **升级边界**：发布者称无需额外迁移操作，仍建议回归测试大结果、审核调用次数和 Bedrock 配置。本文采用 LTS，不以同日开发预发布版替代生产升级建议。

### langchain-quickjs 0.3.12｜支持取消 VM 执行预算，但需独立终止边界

- **发布时间**：2026-11-07 05:00:13 UTC（北京时间 13:00:13）；**状态/许可**：GitHub 非预发布，包元数据仍标 Alpha；MIT。
- [版本公告](https://github.com/langchain-ai/deepagents/releases/tag/langchain-quickjs%3D%3D0.3.12) · [版本文档](https://github.com/langchain-ai/deepagents/blob/langchain-quickjs%3D%3D0.3.12/libs/partners/quickjs/README.md) · [许可与依赖](https://github.com/langchain-ai/deepagents/blob/langchain-quickjs%3D%3D0.3.12/libs/partners/quickjs/pyproject.toml)
- **更新与场景**：面向 Deep Agents 的持久化 JavaScript REPL，加入 `timeout=None`，修复析构时阻塞解释器关闭及工具签名中嵌套 schema 引用解析。适合研究程序化工具调用和中间数据处理的 harness 开发者。
- **关键风险**：默认 5 秒预算只统计 VM 执行，不包含等待宿主工具的时间，本来就不是整体墙钟超时。取消预算后，无限同步执行不能靠外层 asyncio 取消强制终止，需进程隔离和可终止的上层执行边界。该选项不是通用提速开关。
- **兼容性**：依赖下限提高至 deepagents 0.7.34、quickjs-rs 0.2.6、langchain-core 1.7.6。程序化工具调用默认关闭，工具 allowlist 与人工审批仍须单独设计。[相关变更](https://github.com/langchain-ai/deepagents/pull/6958)
