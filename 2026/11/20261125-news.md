## 一、热点事件

### 1. 产品｜Claude 和 Claude Code 扩展 MCP 能力

- **进展（Anthropic，11 月 24 日）：**Skills over MCP 进入公测，Pro、Max、Ultra 默认启用，Team 须由管理员启用，Enterprise 尚待开放。Tasks（异步任务）和 Elicitation（执行中请用户补充信息或确认）已面向前三个计划正式开放，Team 和 Enterprise 正逐步推出。通过该扩展直接向 MCP 服务上传文件仍待推出。
- **为什么值得关注：**工具说明“能做什么”，Skill 提供“什么时候做、按什么步骤做”。异步任务可返回任务 ID，供客户端按轮询间隔查询，任务记录可受保留时间约束。任务有结果，并不等于业务已验收。
- **治理边界：**MCP Skills 的 SEP-2640 已定稿，但客户端支持仍有差异。对有完整文件清单的技能，如果宿主保留单个技能的授权，授权须绑定当时全部文件的 URI 和内容摘要。新增、删除或修改文件，都不能沿用原授权。
- [Anthropic 公告](https://claude.com/resources/articles/skills-over-mcp-tasks-and-more) · [MCP Skills](https://modelcontextprotocol.io/extensions/skills/overview) · [MCP Tasks](https://modelcontextprotocol.io/extensions/tasks/overview)

### 2. 评测｜DeepMind 发布 Humanity’s First Exam（HFE）

- **进展（Google DeepMind，11 月 24 日）：**HFE 包含 544 道基础文本与图像题，覆盖 20 项能力，考查同一问题和轻微变体能否稳定答对。Google 还在 Kaggle 征集当前模型仍会答错的日常题，公告给出的截止日是 12 月 15 日。
- **为什么值得关注：**复杂任务展示能力上限；基础任务的重复通过率更能说明流程是否适合无人值守。评估自己的业务时，可以分别记录每次是否通过、同一场景是否全通过。HFE 本身不衡量企业 Agent 的工具权限、审批或业务结果。
- [Google 官方公告](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/humanitys-first-exam/) · [Kaggle 评测](https://www.kaggle.com/benchmarks/deepmind/hfe)

## 二、模型与产品

### 3. 模型｜MemTensor 面向国内外开发者披露 MemT-1.0-Pro

- **时间（厂商供稿）：**北京时间 11 月 24 日 11:27 经 PRNewswire 分发。ModelScope 已有标注 11 月 22 日的条目，这次可核的是新闻稿分发，不是权重首次可下载。
- **变化：**基于 NVIDIA Nemotron 3 Ultra，554B 总参数、59B 激活。模型卡展示了保存、恢复隐式记忆状态并在不重新读入原对话的情况下继续使用它。互动更新动态状态，不改模型权重。论文中的 128K、约 66 倍持久存储差异，是 Nano 与完整上下文 KV 缓存的对比，不是 Pro 的显存、成本或速度数字。
- **为什么值得关注：**常驻 Agent 可评估快照对连续工作的帮助，但压缩后的记忆不能替代可追溯来源和正式权限记录。模型材料标注 OpenMDW-1.1；另一个 GitHub 仓库的原始软件（含 SGLang 集成）标注 PolyForm Noncommercial 1.0.0；外部依赖另有条款，不把整套组件视作同一许可。
- [MemTensor 新闻稿](https://www.prnewswire.com/news-releases/memtensor-releases-and-open-sources-memt-1-0-pro-a-554b-memory-native-model-302948905.html) · [ModelScope 集合](https://www.modelscope.cn/collections/MemTensor/MemT-10) · [模型卡](https://huggingface.co/MemTensor/MemT-1.0-Pro) · [代码许可证说明](https://github.com/MemTensor/MemT-1.0#-license) · [作者预印本](https://arxiv.org/abs/2610.26825)

### 4. 产品｜Claude 生成的部分 Artifact 可装成桌面应用

- **进展（Anthropic，11 月 24 日）：**Mac 和 Windows 公测可将符合条件的 Artifact 装成应用；打开仍需联网并登录 Claude。Claude Docs、Slides、Sheets 不在可安装范围。应用随 Artifact 更新；桌面权限只覆盖获批版本，更新会再询问，外部数据或内容本身仍可能独立变化。
- **为什么值得关注：**这是缩短桌面原型交付的途径，不等于独立打包、离线部署或绕开组织管理员。评估内部分发时，分别验证登录依赖、权限和更新行为。

## 三、值得关注的开源项目

### 5. SDK｜OpenAI Agents SDK Python v0.26.0（MIT）

- **时间：**GitHub 稳定版于北京时间 11 月 24 日 11:15:47 发布；PyPI wheel 与源码包随后于 11:24:11、11:24:13 上传，均有发布溯源。
- **升级边界：**受旧容器内挂载策略影响的 Docker 会话，需要按更新清单重新创建，不沿用含该旧会话的 RunState；会话与 RunState 的数据结构本身未变。自定义 Realtime 追踪提供器另有禁用状态检查。跨工作进程恢复待批请求属于另一发行线的 GitHub 1.0 alpha，不是该稳定版新增。
- **为什么值得关注：**升级异步 Agent 时，应分开验证新会话、旧会话处理和追踪是否完整，不要只看依赖安装成功。
- [正式 Release](https://github.com/openai/openai-agents-python/releases/tag/v0.26.0) · [PyPI 文件与溯源](https://pypi.org/project/openai-agents/0.26.0/#files)
