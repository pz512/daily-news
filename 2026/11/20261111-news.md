## 三条要点

1. **前沿模型扩大可用范围，价格与许可同样值得看。** Gemini 4 Carbon 面向付费开发者和企业开放；MiniMax H3-Image 开放权重，但地域、收入和托管服务限制使它不能被视作无条件商用的开源模型。
2. **Agent 评测与验证开始更贴近真实交付。** MKA 检查复杂视觉文件和最终工作产物，AlphaProof Code 则把形式化证明推进到特定编译后二进制。两者都需要看清评测设置、可信假设和覆盖范围。
3. **长任务工具补齐中途纠偏、检索与运行控制。** OpenCode、Kimi Code、Haystack 和 Deep Agents Code 发布工程更新；使用前应检查 SDK 兼容、流水线输入次序及本地文件的信任边界。

## 精选内容

### 1. Gemini 4 Carbon 对外开放：长任务能力与临时定价要一起评估

- **时间 / 来源**：官方页面发布时间为 2026-11-10 16:00 UTC，即北京时间 11 月 11 日 00:00；同日报道也确认开放。[Google 公告](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/) · [窗口内报道](https://9to5google.com/2026/11/10/gemini-app-4-carbon/)
- **变化与价值**：付费开发者和企业可通过 Gemini API、AI Studio、Gemini for business 等入口使用；Google AI Ultra 用户在 Gemini App、Search AI Mode 和 Antigravity 等产品逐步获得访问。Google 将其定位于更长程的编码、知识工作和科学推理，适合拿已有复杂任务重新比较完成质量与总调用成本。
- **价格与边界**：每百万输入 / 输出 token 的引入价为 2 / 10 美元，优惠期至 11 月 30 日，之后为 4 / 20 美元。它不是开放权重发布；多 Agent 协作的 `/swarm` 仍是预览功能。厂商榜单与演示不等于独立复测，长推理使用更多 token 也可能抵消单价优势。

### 2. MiniMax 发布 H3-Image 并开放权重：4K 图像之外，先读新许可

- **时间证据**：中文官方公告标注 11 月 10 日；IT之家当日 23:25:52（15:25:52 UTC）报道已发布。英文公告标 11 月 11 日，本期依据中文公告与窗口内报道收录，不据此声称精确上线时刻。[中文公告](https://www.minimax.cn/blog/minimax-h3-image) · [带时刻报道](https://www.ithome.com/1/025/191.htm)
- **能力与用途**：支持文生图、参考图生成与图像编辑，官方称可处理最多 16 张参考图，并在 10 秒内生成 4096×4096 图像。适合关注高分辨率素材和多参考图工作流；速度、质量与硬件条件需自行复测，不能把演示延迟当作任意设备的保证。
- **许可提醒**：权重采用 **MiniMax-H3-Image Community License**，不是 Apache / MIT。适用地域排除欧盟、英国、韩国和美国；用户或关联方年化收入超过 **100 万美元**，或向第三方提供托管服务，均须另获事先书面授权。商业界面还有标识等要求，不能沿用旧 H3 的许可门槛。[权重与模型卡](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image) · [本模型许可原文](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image/blob/main/LICENSE)

### 3. AlphaProof Code：用 Agent 生成证明，检查特定 libsignal 机器码的安全性质

- **时间 / 来源**：官方页面元数据为 11 月 10 日 12:00 UTC（北京时间 20:00），官方 RSS 记录为 12:02:28 UTC。[研究公告](https://deepmind.google/blog/introducing-alphaproof-code/) · [技术报告](https://google-deepmind.github.io/code-verification/) · [官方 RSS](https://deepmind.google/blog/rss.xml)
- **方法与价值**：人类专家审阅 Lean 规格，Agent 生成证明，再由机械检查器验收。报告披露约 650 万行证明，目标是以 `libsignal v0.105.4` 和 `spqr v1.6.0` 构建的 AArch64 CLI 二进制，覆盖部分握手、认证和保密性质。价值在于把代码实现与形式化规格连接起来，而不只验证算法描述。
- **研究边界**：这不是“整个 Signal 手机应用已被证明绝对安全”。证明依赖密码原语等可信契约和环境假设，不覆盖完整群聊、多设备等场景；计算安全证明针对经典攻击者，符号证明另有假设。本文未独立重跑 Lean，也不把技术报告当成已完成同行评审的定论。
- **材料许可**：主体代码为 Apache-2.0，第三方 `libsignal` 材料保留 AGPL-3.0-only 等原有许可，不能把整仓统一当作 Apache。[仓库与复验说明](https://github.com/google-deepmind/code-verification)

### 4. MKA 新评测：能否看懂复杂文件，并交出可用产物

- **时间 / 来源**：官方页面发布时间为 11 月 10 日 16:00 UTC，即北京时间 11 月 11 日 00:00。[Google 方法说明](https://blog.google/innovation-and-ai/models-and-research/gemini-models/multimodal-knowledge-agent-benchmark/)
- **测什么**：Google 与 Artificial Analysis 合作推出 200 项任务，覆盖 10 个行业、83 类职业，要求处理图纸、图表等视觉文件并完成交付。各模型使用统一的 Stirrup 执行框架和工具、沙箱、轮数预算；每题约 70 项检查，事实准确性占 75%，视觉设计占 25%。
- **怎么读结果**：完整 200 题保持私有，仅公开 10 个样例，因此无法仅凭公开样例复现完整排名。Google 报告 Carbon 质量第二、平均任务成本约为首名的六分之一；这是共同开发评测中的结果，不是通用能力排序。对企业更有用的是借鉴其交付件检查方法，并用自有文件复测。

## 值得关注的开源项目

以下四条独立于上述精选，均已核实为窗口内的**正式 release**，不是预发布。代码许可不自动覆盖接入的模型、API 服务或第三方内容。

### OpenCode v2.2.7｜运行中纠偏与 MCP 登录修复，含 SDK 破坏性变更

- **发布时间 / 许可**：11 月 10 日 10:37:15 UTC（北京时间 18:37:15），MIT。[版本公告](https://github.com/anomalyco/opencode/releases/tag/v2.2.7) · [版本许可](https://github.com/anomalyco/opencode/blob/v2.2.7/LICENSE)
- **更新**：ACP 客户端可通过 steering 重定向正在执行的 turn；Copilot Auto 增加自动路由，但需账号具备 Auto pool。远程 MCP 的并发 refresh-token 轮换与临时刷新故障不再轻易导致退出登录。
- **迁移重点**：直接使用 `@opencode/ai` 的代码要把 `ImageResponse.image` 改为 `images[0]`；部分 SDK 端点不再等待插件全部加载，应监听相应 `*.updated` 事件刷新，避免把暂未加载的条目误判成永久缺失。

### Kimi Code CLI 2.5.3｜中断模型请求后在同一轮继续

- **发布时间 / 许可**：11 月 10 日 13:06:23 UTC（北京时间 21:06:23），MIT。[版本公告](https://github.com/MoonshotAI/kimi-code/releases/tag/%40moonshot-ai/kimi-code%402.5.3) · [版本许可](https://github.com/MoonshotAI/kimi-code/blob/%40moonshot-ai/kimi-code%402.5.3/LICENSE)
- **更新与价值**：steering 现在可中断活跃模型请求并在同一 turn 接续；新增 `POST /api/v1/sessions/{session_id}/steer`，便于 IDE 或服务端控制台发出纠偏消息。另修复 Windows 上通过 `npx` 等脚本命令启动 stdio MCP 服务器失败的问题。
- **边界**：这是 Agent 控制和兼容性更新，不是新模型发布。工程上仍需区分“停止生成”和“撤销已执行操作”，不能把中断请求视作命令回滚；模型服务的条款和费用另计。

### Haystack v3.5.0｜多向量精排与结构化输出，注意旧流水线顺序

- **发布时间 / 许可**：11 月 10 日 12:34:55 UTC（北京时间 20:34:55），Apache-2.0。[版本公告](https://github.com/deepset-ai/haystack/releases/tag/v3.5.0) · [版本许可](https://github.com/deepset-ai/haystack/blob/v3.5.0/LICENSE)
- **更新与用途**：新增 `Document.multivector_embedding` 与 `MaxSimRanker`，面向 ColBERT 类 late-interaction 文档精排；`StructuredOutputHook` 可校验最终 JSON / Pydantic 输出，并将错误反馈给模型重试。
- **升级风险**：多发送者输入改按 `Pipeline.connect()` / YAML `connections` 顺序排列，旧流水线中 `DocumentJoiner` 的权重可能因此对应不同检索器，必须回归。部分 OpenAI 组件默认模型也变化，建议显式固定 `model`。官方称多向量支持仍是第一步，相关 embedder 集成尚在推进，不能写成全链路即插即用。

### Deep Agents Code 0.2.7｜降低 Git 探测开销，完善长会话反馈

- **发布时间 / 许可**：11 月 10 日 21:00:39 UTC（北京时间 11 月 11 日 05:00:39），MIT；同窗 00:12:45 UTC 的 0.2.6 合并关注，不另计一条。[0.2.7](https://github.com/langchain-ai/deepagents/releases/tag/deepagents-code%3D%3D0.2.7) · [0.2.6](https://github.com/langchain-ai/deepagents/releases/tag/deepagents-code%3D%3D0.2.6) · [版本许可](https://github.com/langchain-ai/deepagents/blob/deepagents-code%3D%3D0.2.7/libs/code/LICENSE)
- **更新**：0.2.7 增加 shell 补全、减少 Git attribution 探测与失败重试开销，并提供关闭选项；修复 Windows 编辑器启动及不流式返回摘要时的压缩反馈。0.2.6 补充 idle compaction / offload 追踪与启动恢复修复。
- **使用提醒**：这是终端应用的版本，不是昨天已发布的 Deep Agents SDK 0.7.35。官方说明默认信任启动目录，项目内容可能在审批前读取；处理不可信仓库应使用沙箱。[安全边界说明](https://github.com/langchain-ai/deepagents/blob/deepagents-code%3D%3D0.2.7/libs/code/README.md)

### 国际｜n8n Labs 推出 Nod 研究预览，把个人 Agent 放到本地运行

- **时间 / 许可**：官方公告发布时间为 11 月 10 日 12:52:49 UTC（北京时间 20:52:49）；主体代码 Apache-2.0，第三方组件保留各自条款。[发布博客](https://blog.n8n.io/meet-nod/) · [仓库与许可说明](https://github.com/n8n-io/nod)
- **产品变化**：独立于 n8n 的个人 Agent 应用，使用本地工作环境和浏览器，可选模型供应商，并提供记忆、后台 / 定时任务、操作记录与费用限制。当前为研究预览，Windows 版本也标注 preview。
- **隐私与可靠性**：本地运行不代表任务数据不出机，模型供应商仍会收到任务所需内容，默认连接服务和使用数据也须检查。许可判断依赖模型，可能出错；在本机运行时，电脑休眠会影响任务执行。不能把日志、审批和沙箱当作绝对安全保证。
