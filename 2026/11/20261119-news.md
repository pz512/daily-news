## 精选新闻与研究

### 1. Gemini 4 Neon 发布：面向长任务的速度、成本与控制

- **时间 / 来源**：Google 官方稿标注 **2026-11-18**，未取得精确发布分钟。[发布原文](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-neon/)
- **发生了什么**：宣布向 Gemini API / AI Studio、Gemini for business，以及符合条件的 Antigravity、Gemini 应用订阅用户推出。上下文为 100 万 tokens；标准 API 每百万输入、缓存输入、输出 tokens 分别为 **3、0.15、15 美元**。
- **为什么重要**：官方把多步执行、用户中途纠正、压缩上下文及减少重复读取列为重点，不只是提高单轮问答分数。
- **边界**：排名、单任务成本和安全指标均按 Google 披露，本期未复测；不同 Harness 的成绩不能直接互换。面向网络防御的版本计划随后经 Fairwind 向可信防御者推出，不等于今日所有账户均可使用。

### 2. OpenAI 披露 AI 辅助芯片设计：生产优化与评测分开看

- **时间 / 来源**：官方稿 **2026-11-18**，只核到日期。[研究原文](https://openai.com/index/advancing-chip-design-with-our-models/)
- **发生了什么**：OpenAI 称模型参与 Jalapeño 电路优化，并与 AMD、Synopsys 合作。Jalapeño 向量和矩阵单元标准单元面积节省估计约 13%、10%，称已经硅片验证；AMD 部分设计改动已进入送厂制造设计。
- **研究边界**：另一个 RISC-V 评测使用 PicoRV32 与 Ibex，依靠仿真和频率估计评分，允许面积最高达到原设计 16 倍。从规格重新设计还可能省去原内核的某些功能，不能将该成绩直接理解为生产芯片等比例提速。
- **为什么重要**：模型输出要经过行为等价与功耗、性能、面积检验，展示的是人类工程流程中的优化，不是独立设计制造完整芯片的证明。

### 3. DSH Univer Office v0.5.0：工具按需加载

- **时间 / 来源**：GitHub Release **2026-11-18 07:21:40 UTC**，北京时间 15:21:40。[Release](https://github.com/dream-num/dsh-univer-office/releases/tag/v0.5.0)
- **变化**：默认在会话加载内置 Univer / Office skill 后的下一步才暴露 univer_* 工具；activationSkills 可配置触发技能，空列表可恢复从首步加载。SDK 升至 1.5.2，现有 v3 文件不需迁移。

### 4. OpenCode v2.3.1 / v2.3.2：后台任务与 GPT‑6.2 缓存修复

- **时间 / 来源**：分别发布于 **11 月 18 日 00:17:57 / 01:35:12 UTC**，北京时间 08:17:57 / 09:35:12。[v2.3.1](https://github.com/anomalyco/opencode/releases/tag/v2.3.1) · [v2.3.2](https://github.com/anomalyco/opencode/releases/tag/v2.3.2)
- **变化**：2.3.1 默认开启后台压缩，shell 超时后转入后台而非直接终止；接入 GPT‑6.2，并把实验 schedules 扩展为 automations。2.3.2 将 Responses 路由的系统提示改为前置 developer 消息，以修复 GPT‑6.2 重复按未缓存输入计费的问题。
- **为什么重要**：成本取决于请求布局和缓存，而非只看模型标价；发布方给出的 token 节省是特定测试结果，不代表每个任务同等节省。
- **迁移提醒**：后台摘要即使未使用也会耗费 tokens；旧实验条件或运行次数限制的 schedule 不保证迁移。超时不再表示进程已停止，应检查后台任务与终态。

## 安全公告

### 6. Pydantic AI Harness：JWT 脱敏可能阻塞事件循环

- **时间 / 来源**：官方公告 **2026-11-18**，只核到日期。[GHSA-5m5q-5qj4-gx9h](https://github.com/pydantic/pydantic-ai/security/advisories/GHSA-5m5q-5qj4-gx9h)
- **影响**：pydantic-ai-harness **0.16.0–0.69.0**。使用含 jwt 模式的 redact_secrets / secret_data() 处理攻击者可影响的提示、工具结果或模型输出时，正则回溯可能以平方时间消耗事件循环，拖慢同进程其他请求。
- **处置**：官方修复版本为 **0.70.0**，建议升级至该版或更新版本；无法升级时，官方提供显式排除 jwt 检测模式的临时办法，但这会减少检测覆盖，需要评估取舍。本期未运行攻击样本，也没有用户部署受影响的证据。

### 7. Pydantic AI Harness：ANSI 清理在截断前也可能耗尽时间

- **时间 / 来源**：官方公告 **2026-11-18**，只核到日期。[GHSA-m4cr-m4qc-9hh3](https://github.com/pydantic/pydantic-ai/security/advisories/GHSA-m4cr-m4qc-9hh3)
- **影响**：pydantic-ai-harness **0.4.0–0.69.0**，条件是 ToolOutputLimits 启用 strip_ansi=True，且工具输出可受攻击者影响。清理发生在输出缩减之前，因此现有输出长度限制不能限制这部分开销。
- **处置**：升级至 **0.70.0 或更新版本**；临时保持 strip_ansi=False。Pydantic AI v1 无法把 Harness 升过 0.4.0，需要迁至 v2 配合修复版，或暂不开启该功能。此项是可用性风险，不据此推断凭据已泄露；本期未复现。

## 热点、长文与方向辨析

### 8. Dean Ball《The Silent Consensus》：讨论委托与人类控制权

- **时间 / 来源**：OpenAI 网站 **2026-11-18**刊载。[全文](https://openai.com/index/the-silent-consensus/)
- **内容**：文章改编自哈佛讲座，讨论单次合理的 AI 委托如何累积为人类机构失去实际控制；主张可理解且有限的权限、可审计的行动，以及可撤回的授权。
- **边界**：原文明确是作者个人观点，不必然代表 OpenAI；不是模型发布或已验证的未来预测，也不将旧讲座日期冒充新访谈。

### AI Native / Harness / RSI

- **AI Native**：芯片设计案例的价值在于把模型输出放回验证工具与实际工程约束，不是让语言模型自证结果正确。
- **Harness**：按需加载、提示缓存、任务终态、输入处理复杂度会同时影响成本和可靠性。Pydantic 两项公告提醒：安全过滤器自身也需要资源边界。
- **RSI**：模型辅助 RTL 优化、人工部署补丁、工具编排改善，都不等于系统已自主完成持续自我训练和升级。本期不以“AI 设计 AI 芯片”直接证明递归自我改进。
