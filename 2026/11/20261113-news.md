## 三条要点

1. **模型产品继续向专用工作流分层。** 百度发布文心闪电深度思考与文心一镜微表情，火山推出 Seedance 2.5 flash；成本、速度和效果数字仍主要是厂商口径。
2. **企业 Agent 把持续运行和安全治理放在一起。** Google Data Cloud、Databricks Genie ZeroOps、Anthropic 新版使用政策都强调数据权限、人工控制和高风险边界。
3. **开源工具更新集中在恢复、浏览器隔离、支出与记忆外传控制。** OpenHands、LangGraph、browser-use、Nod、claude-mem 等更像工程可靠性和治理升级，不等于模型能力跃升。

## 值得关注的独立开源项目

### PyTorch ExecuTorch v1.6.0｜边缘推理后端与批量服务扩展

- **发布时间 / 许可证**：2026-11-12 17:01:41 UTC；BSD 三条款。[Release](https://github.com/pytorch/executorch/releases/tag/v1.6.0) · [许可证](https://github.com/pytorch/executorch/blob/main/LICENSE)
- NXP Neutron 进入 production-ready，TensorRT backend 为 Beta；新增 LeRobot SmolVLA 或 pi0 在 CUDA、MLX、OpenVINO、XNNPACK 的支持，torch-free Python runtime，以及 batched serving、prefix cache 和 DFlash speculative decoding。
- 适合端侧、移动和嵌入式推理；Python 3.10 与旧 CUDA wheel 移除，CUDA 13.4 wheel 取代部分旧版本，Jetson Orin 需要源构建，升级要做后端回归。

- 适合大模型训练和推理优化；后端变化面较大，MPS 流程仍限制 torch<2.15，需按硬件逐项测试。

### AI Native｜从回答转向可持续、可治理的工作面

Google Data Cloud connectors、Databricks Genie ZeroOps 和 Nod 的本地文件能力都把 Agent 放进持续运行的数据或操作环境。价值在于状态、权限、可恢复性和支出上限同时可见；这不等于 Agent 已能在没有人工审批的情况下安全完成开放任务。

GitHub 的 Agent Skills 实践指南（11 月 12 日，日期级证据）建议以版本化 SKILL.md、宿主工具/权限清单、独立验证 Agent 和人工检查点组织可复用技能；文中明确提醒“自我验证不等于验证”。这是工程方法与案例，不是独立基准或产品发布。[指南](https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills/)

### Harness / RSI 辨析

claude-mem 的 eve 记忆循环、LangGraph 的命名空间与部署修复，以及 PydanticAI 的持久子 Agent 和审批，都属于人为设计的记忆、控制流或运行时增强。OpenAI 对自动红队改进模糊鲁棒性的研究文章（11 月 12 日，日期级证据）报告了受控实验中的收益，但作者也限定为模型层防御，不等于生产安全或通用 RSI。[研究](https://alignment.openai.com/fuzzy-robustness/)

这些材料没有提供模型自主递归改进通用能力的证据；本期未核验到可独立支持 RSI 突破的新论文或实验。
