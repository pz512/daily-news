### 1. 【机器人发布】蚂蚁灵波把三维建图与目标导航拆成建图和导航两个项目
**来源：Robbyant 公司公告，11 月 27 日 16:10 北京时间。** LingBot-Map 2.0 面向连续视频的三维建图，LingBot-Navi 面向根据图像、文本或物体类别找目标。厂商披露，Navi 在 GOAT-Bench 仿真的端到端成功率为 **56.09%**；在 GOAT-Bench 子集上由仿真器代执行导航的另一口径为 **68.60%**，不能解读为导航模型自身提升了 12.51 个百分点。Map 的推理代码早在 11 月 21 日已发布，Navi 仓库也把首发标为 11 月 26 日。本期收录的是窗口内的联合公告，不把此前材料算作今天首次上线。**为什么重要：** 可以分开测试建图稳定性、目标选择和实际走到目标的能力，不必用单一成功率掩盖失败环节。许可与试用边界见下方开源栏目。  
[公司公告](https://via.tt.se/pressmeddelande/4660319/robbyant-open-sources-lingbot-map-20-and-lingbot-navi-enabling-long-term-spatial-memory-and-autonomous-navigation-for-robots?lang=en&publisherId=259167)

## 精选进展

### 3. 【工程博客】同一台 Trainium3 上，视频生成要分开看冷启动和热运行
**来源：Hugging Face 工程师 David Corvoysier，11 月 27 日。** 作者用一台 AWS trn3.48xlarge 的 32 个 NeuronCore（整机 64 个）运行 LTX-2.5：模型加载后，一段 10 秒、2048×1024 的带声视频耗时约 **22–23 秒**；文中另报加载约 3 分钟，首条约 80 秒。**为什么重要：** 适合参考视频推理的并行拆分和部署评测；选型要分别记首次请求、连续生成和成本，不能把不同分辨率、不同核数的结果当成等条件提速。  
[Hugging Face 原文](https://huggingface.co/blog/video-trainium3) · [实验代码](https://github.com/dacorvo/video-generation)

### 4. 【企业产品】Netweb 推出可本地部署的 GPU 数字工作空间
**来源：Netweb Technologies 递交印度交易所的产品公告，11 月 27 日。** Skylus Workspaces 把虚拟桌面、企业应用、容器和 GPU/HPC 资源纳入统一工作空间，面向本地部署和私有云；厂商列出身份集成、角色权限和自动分配资源等能力。**为什么重要：** 私有计算环境可以从“为每个岗位配机器”转向“按权限和需求分配环境”。公告不是实际客户验证，采购前应单测 GPU 配额、跨用户隔离和会话回收。  
[交易所披露的公司原文（PDF）](https://nsearchives.nseindia.com/corporate/NETWEB1234_27112026075412_Intimation_Press_Release_Product_Launch.pdf)

### 5. 【研发工具】Copilot CLI 1.0.117 支持为自定义 Agent 显式选择工具
**来源：GitHub 官方版本说明，11 月 27 日。** 新版本允许自定义 Agent 显式选择可见工具；子 Agent 即使没有自定义提示词，也遵循角色文件里的工具列表。版本说明还列出两项长任务改进：重启并恢复会话后，后台 Agent 可以继续对话；自动压缩只有在检查点保存成功后才提示已保存。**为什么重要：** 做只读调研或代码评审的 Agent 可以只暴露任务所需工具，但工具列表不等于调用审批或后端授权。可用一次重启恢复测试，分别验证任务继续运行、检查点已持久化，以及恢复后工具权限没有扩大。  
[GitHub Copilot CLI 1.0.117](https://github.com/github/copilot-cli/releases/tag/v1.0.117)

## 值得关注的开源项目

### 6. 【主分支更新】vLLM Agentic API：本地推理和 HTTP 上游共享执行层
**来源：vLLM 项目主分支提交，11 月 27 日；Apache-2.0。** `/v1/responses` 直连本地 vLLM 引擎时，与 HTTP 模式复用历史、工具、会话、压缩和持久化逻辑。**适用场景与限制：** 适合比较同一 Agent 在不同后端的行为。直连模式只支持单副本，尚待真实 GPU 与模型验证；Messages API 不在本次直连范围内，Claude Code 仍需配置 HTTP 上游。  
[合并提交](https://github.com/vllm-project/agentic-api/commit/d4fcf64) · [PR 与限制](https://github.com/vllm-project/agentic-api/pull/382)

### 7. 【预发布】llama.cpp：本地聊天可主动把 Agent 轨迹分享为数据集
**来源：llama.cpp b12811 发布说明，11 月 27 日；仓库代码 MIT。** 用户可以把整场对话或某条消息之前的分支以 JSONL 格式主动上传到 Hugging Face 数据集；新建数据集在分享界面中默认公开，除非勾选私有。**适用场景与限制：** 用合成数据复盘工具调用失败、积累评测集；本地跑模型不代表分享到外部后数据还留在本地。涉及内部内容时先脱敏并检查目标的访问范围。  
[llama.cpp b12811](https://github.com/ggml-org/llama.cpp/releases/tag/b12811)

### 8. 【稳定版】Kilo Code 7.8.40 收紧自动批准的配置范围
**来源：Kilo Code 稳定版说明，11 月 27 日；MIT。** 本次稳定版纳入此前预览版的权限变更：VS Code 端的自动批准只读写用户级设置，关闭自动批准会中止还在重试的自动授权；权限卡也会把不可见字符显示为可读的转义形式。**适用场景与限制：** 更便于人看清正在批准的操作。升级后应确认原来依赖项目配置的自动化是否改为询问，以及用户设置有没有过宽。  
[Kilo Code 7.8.40](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.40) · [仓库与许可](https://github.com/Kilo-Org/kilocode)

**热点项目的获取与许可（见第 1 条）：** [LingBot-Map 2.0](https://github.com/Robbyant/lingbot-map-v2) 的仓库标注代码与本次基础权重为 CC BY-NC 4.0，不宜直接用于商业交付；仓库提供的是因果流式基础模型代码，不是论文中的完整混合方案；README 仍注明权重仓库为私有，下载需有权限的账号。[LingBot-Navi](https://github.com/Robbyant/lingbot-navi) 仓库标注代码和权重为 Apache-2.0。实地使用前应另测遮挡、照明变化和场景迁移。
