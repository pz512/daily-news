## 三条要点

1. **决策与科学模型走向专用化，但访问边界更具体。** Gemini Decisions API 把多模态输入变成闭集决策；AlphaGenome 2 以细胞类型为条件预测 DNA 变异；ERNIE 5.5 Flash 与 Qwen4-Max 则仍是有明确期限或训练未完成的预览，不应当作最终版。
2. **长任务 Agent 正在接管流程，但“可持续运行”不等于已普遍可用。** Databricks Genie 2 把目标、子 Agent、权限和人工决策串起来；其新 always-on、搜索和管理能力仍分批进入 preview/beta，厂商基准也不能替代真实企业回归。
3. **开源基础设施的重点从“能跑”转向事件流、验证和安全默认值。** Codex CLI、MCP Ruby SDK、Ragas 和 TPU 推理工具都在补控制面；升级前要看破坏性变更、协议兼容、许可证和是否只是发布汇总。

## 精选内容

### 1. Gemini Decisions API：把多模态输入变成可审计的闭集决策

- **时间 / 来源**：Google 官方结构化元数据为 2026-11-11 18:00 UTC（北京时间 11 月 12 日 02:00），在本期窗口内。[官方公告](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/)
- **变化与用途**：Gemini Decision 1 面向文本、图像、音频、视频和 PDF，单输入最多 256K token；一次请求最多评估 1000 个 yes/no、choice 或 rubric 问题，并返回答案、概率和置信度。官方把它定位为工具选择、策略检查、路由和上下文评分，而不是开放式长文生成。
- **价格与边界**：Google 宣称端到端 150–250 ms、输入每百万 token 0.10 美元且输出 token 免费；这些是厂商口径。闭集问题的标签设计、阈值和人工升级策略决定实际可靠性，不能将“置信度”直接当作校准后的风险概率。

### 2. AlphaGenome 2：把 DNA 变异影响细化到细胞类型

- **时间 / 来源**：Google DeepMind 官方页面的结构化元数据为 2026-11-11 15:00 UTC（北京时间 23:00），网页正文日期同为 11 月 11 日。[官方公告](https://deepmind.google/blog/alphagenome-2-deciphering-how-cells-read-dna-to-better-understand-disease/) · [论文 PDF](https://storage.googleapis.com/deepmind-media/DeepMind.com/Blog/alphagenome-2-deciphering-how-cells-read-dna-to-better-understand-disease/alphagenome-2.pdf)
- **变化与价值**：条件式模型在百万字母 DNA 序列之外接收组织、细胞类型或状态；训练材料超过 1.07 亿个单细胞档案、覆盖 68 种组织，可预测基因表达、组蛋白修饰、染色质可及性和 DNA 甲基化。官方称在 TenK10K（28 种免疫细胞）上识别因果变异 30% 对比原模型 16%，方向性基因效应 43% 对比 23%。
- **许可与边界**：当天开放的是非商业研究 API，商业研究为 private preview，不是开放权重；官方明确仅限研究用途，尚未获临床或诊断验证。上述提升来自厂商报告，仍待独立复现，不能转写为医学结论。

### 3. 百度 ERNIE 5.5 Flash Preview：280B 稀疏模型先给开发者试用

- **时间 / 来源**：新华网报道时间为 2026-11-11 14:18:34 CST（06:18:34 UTC），百度官方页同步给出 Preview 说明。[官方发布页](https://ernie.baidu.com/release/ernie-5-5-flash-preview/) · [新华网报道](https://www3.xinhuanet.com/tech/20261111/183aa161e70b4942b622e10b5e3da605/c.html)
- **变化与用途**：官方披露总参数 280B、激活参数 14B、上下文 1M，可通过千帆 API 试用，并计划在 11 月 25 日前开放权重。适合关注长上下文和代码、3D/游戏等工作流，但性能数字尚缺独立复测。
- **预发布边界**：百度声明这是后训练尚未完成的中间 Preview，可能存在缺陷，不应写成最终版或稳定生产能力。权重发布前的许可证、可用地域和托管条件仍需以模型页为准。

### 4. Qwen4-Max-Preview：阿里云限时 Token Plan 预览

- **时间 / 来源**：阿里云官方文档规定预览期为 11 月 11 日 10:00 至 11 月 25 日 24:00（UTC+8），即 02:00 UTC 起；文档未把它写成正式 Qwen4 GA。[官方文档](https://help.aliyun.com/en/model-studio/qwen4-max-preview)
- **变化与边界**：支持文本、图像、视频、深度推理、函数/网页工具调用、结构化输出和 1M 上下文，兼容 OpenAI Chat Completions/Responses 与 Anthropic Messages。仅限 Token Plan，预览结束后退役，且未公布开放权重或独立基准。
- **使用提醒**：它是受限预览服务，不应与正式版模型、开源权重或长期 API 兼容性混写；迁移前要确认下线日期和账单口径。

### 5. Databricks Genie 2：企业 Agent 持续跟踪目标并在需要时找人决策

- **时间 / 来源**：Databricks 官方新闻稿标注 2026-11-11，未公开具体时分。[官方新闻稿](https://www.databricks.com/company/newsroom/press-releases/databricks-launches-new-always-genie-autonomous-ai-complex)
- **变化与价值**：新一代 Genie 可接收目标、持续运行、委派子 Agent、追踪进度、追问缺失输入，并通过优先级收件箱和邮件把决策点交回人类。Genie Ontology 连接业务定义、数据、人员与流程，Unity Catalog / Unity Gateway 负责权限、审批、花费上限和审计。
- **可用性与边界**：Genie 与 Genie Ontology 已 GA；新的 always-on Genie、Genie Search 和 Ontology Manager 进入后续 preview/beta。Databricks 与 Turing 的 91% 通过率、少于一半 token 等数字来自单一构造工作区和厂商评测，不能替代企业自有数据、权限和失败恢复测试。

### 6. BotPsy-0.8B：面向本地设备的开源小型 Agent 模型

- **时间 / 来源**：QVAC 官方博客与 Tether AI Research 新闻稿均标注 2026-11-11，无公开时分。[QVAC 介绍](https://qvac.tether.io/blog/on-device-ai-agent-botpsy) · [Tether 新闻稿](https://tether.io/news/tethers-800m-ai-agent-beats-models-2-5x-its-size/)
- **变化与许可**：模型基于 Qwen3.5-0.8B，面向端侧工具调用；官方称权重采用 Apache-2.0。公司报告 BFCL v4、ACEBench、tau-bench 等成绩高于若干同规模模型，并主张在 1.2B 以下测试模型中领先。
- **独立边界**：Hugging Face 编辑指出结果依赖提示、工具和评分设定，BrowseComp-Plus 仅 4.5；应把它视作窄工作流候选，而不是通用自主 Agent。部署仍需确定性权限、工具白名单和离线失败策略。
