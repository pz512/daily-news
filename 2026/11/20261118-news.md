## 精选新闻

### 1. OpenAI 发布 GPT‑6.2 Astra 与 Sol
- **时间 / 来源**：官方社区公告首帖 `created_at` 为 **2026-11-17 18:00:37.118 UTC**，即北京时间 **11 月 18 日 02:00:37**，明确落在本期窗口内。[公告](https://community.openai.com/t/gpt-6-2-astra-and-sol-are-now-available/1417531) · [时间元数据](https://community.openai.com/t/1417531.json) · [OpenAI 发布原文](https://openai.com/index/introducing-gpt-6-2-astra-sol/)
- **发生了什么**：OpenAI 宣布两款模型面向 Plus、Pro、Enterprise 和 Edu 用户在 ChatGPT Work、Codex 开放，开发者可通过 API 使用 `gpt-6.2-astra` 与 `gpt-6.2-sol`。企业与教育工作区还受管理员启用条件约束。Astra 定位复杂专业项目，Sol 定位高效率日常和多步代理工作。
- **价格 / 边界**：官方标准 API 每百万 tokens 输入 / 缓存输入 / 输出报价分别为 Astra **8 / 0.40 / 40 美元**、Sol **2 / 0.10 / 10 美元**；不将标准价当作 Ultrafast 报价。能力和单任务成本改善均为厂商口径，本期未独立复现，也未执行付费调用。
- **为什么重要**：这是真正落在窗口内的模型与服务发布，不能被工具链更新掩盖。接入前应以自己的长任务评测核对输出质量、总成本和阻塞披露，而非仅比较每 token 价格。
