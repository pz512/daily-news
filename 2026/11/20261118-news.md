### 1. OpenAI 发布 GPT‑6.2 Astra 与 Sol
- **时间 / 来源**：官方社区公告首帖 `created_at` 为 **2026-11-17 18:00:37.118 UTC**，即北京时间 **11 月 18 日 02:00:37**，明确落在本期窗口内。[公告](https://community.openai.com/t/gpt-6-2-astra-and-sol-are-now-available/1417531) · [时间元数据](https://community.openai.com/t/1417531.json) · [OpenAI 发布原文](https://openai.com/index/introducing-gpt-6-2-astra-sol/)

### 8. 安全提示｜agent-framework 两个 PyPI 版本含凭据窃取代码

- **时间 / 来源**：[OpenSSF 固定版本记录 MAL-2026-20101](https://github.com/ossf/malicious-packages/blob/5f547b67f2daa8aa50d74a937b4c2077cccc495b/osv/malicious/pypi/agent-framework/MAL-2026-20101.json)的 `published` 为 **2026-11-17 22:12:19 UTC**（北京时间 **11 月 18 日 06:12:19**），落在本期窗口；记录称两个恶意版本分别于 17 日 20:35、21:08 UTC 发布。[GHSA-764m-3ppc-5m73](https://github.com/advisories/GHSA-764m-3ppc-5m73)于 **11 月 18 日**收录，仅作补充交叉验证，不拿 GHSA 的收录日期替代事发或 OpenSSF 记录时间。
- **受影响范围**：PyPI 包 `agent-framework` 的 **1.26.1、1.26.2**。记录称这两个版本已移除，**1.26.0 及更早版本不受此次恶意代码影响**；GHSA 的 patched versions 为 None，不能解释成已有新修复版。
- **影响 / 条件性处置**：恶意 `.pth` 钩子可在 Python 解释器启动时触发，无须显式导入业务包，窃取环境变量、凭据文件及云 / CI 令牌。**若曾安装这两个版本，应将环境内可访问凭据视为已泄露，撤销或轮换，并检查相关访问日志。** 不要仅升级了事，也不要在可疑环境中直接启动 Python / pip 做检查，以免再次触发；优先隔离、由安全人员通过非 Python 手段检查并重建干净环境，同时排查缓存与镜像中的恶意包。
- **边界**：本期未检查读者设备、依赖或 CI，**没有用户自身受影响的证据**。现有来源不支持断言具体入侵入口或攻击归属，不将“发布凭据可能失陷”写成已确认根因。

## 热点与方向辨析

- **AI Native / Harness**：模型可替换性、双跑评测、权限和回滚应成为 Harness 的默认能力；MAI Code 2 的接入与旧版退役是具体供应链例子。
- **RSI / AI Self-improvement**：OpenAI 在 [GPT‑6.2 发布原文](https://openai.com/index/introducing-gpt-6-2-astra-sol/)称 Astra 是其首个达到 AI Self-improvement「High」阈值的对外发布模型；该阈值衡量辅助加速 AI 研究的能力。它不等于已证明模型能自主训练、验证并部署更强后继，也不能直接当作持续递归自我改进（RSI）已实现。
